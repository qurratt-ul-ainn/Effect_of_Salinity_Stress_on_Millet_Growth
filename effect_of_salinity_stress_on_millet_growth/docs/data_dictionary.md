# Data dictionary

| Variable | Meaning |
|---|---|
| `pot_id` | Experimental pot identifier |
| `treatment` | Salinity treatment code |
| `salinity_level` | Descriptive salinity category |
| `target_ec` | Target electrical conductivity |
| `replication` | Experimental replication |
| `seeds_sown` | Number of seeds sown |
| `plants_emerged` | Number of emerged plants |
| `emergence_pct` | Emergence percentage |
| `plant_height_cm` | Plant height |
| `leaves_per_plant` | Leaves per plant |
| `root_length_cm` | Root length |
| `shoot_fresh_weight_g` | Shoot fresh weight |
| `shoot_dry_weight_g` | Shoot dry weight |
| `root_fresh_weight_g` | Root fresh weight |
| `root_dry_weight_g` | Root dry weight |
| `total_dry_biomass_g` | Total dry biomass |
| `relative_growth_pct` | Relative growth percentage |

The original workbook in `data/raw/` is preserved unchanged.
